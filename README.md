# 个人网站

一个**可直接上线、源码可随时修改**的交互型个人网站，由 Ardot 设计稿（Z 世代柔和粉彩风格）生成而来。
覆盖 9 个页面：首页 / 关于我 / 教育背景 / 实习经历 / 项目经历 / 荣誉 / 技能 / 联系 / 生活。

## 交互特性（鼠标移上去就能感受到）

| 元素 | 效果 |
|---|---|
| 首页 Hero 人像 | 默认呼吸式上下漂浮；鼠标进入挥手 + 弹出「👋 你好呀！」气泡；鼠标移动时跟随做 3D 倾斜 |
| 顶部导航 / 按钮 / 语言切换 | hover 气泡感上浮（放大 + 珊瑚阴影）；按下回弹；点击涟漪（导航珊瑚色、按钮白色） |
| 卡片（能力 / 项目 / 荣誉 / 联系 / 技能） | hover 珊瑚色微光阴影 |
| 生活页 4 张兴趣卡 | 默认漂浮；hover 摆动 + 弹出「⚽ / 🏀 / 🎾 / 🛹」气泡 |
| 旅行 / 创作时间线 | 横向滚动条；卡片 hover 微光

> 想调动画强度？所有 keyframes / 时长 / 阴影都在 `css/style.css` 末尾的「交互增强」区块。

## 本地预览

任意方式启动一个静态服务器即可（直接双击 html 也能看，但部分浏览器对本地文件的限制会影响字体/脚本，推荐用服务器）：

```bash
# 在项目根目录执行
python3 -m http.server 8000
# 然后浏览器打开 http://127.0.0.1:8000
```

## 如何修改（重点：都可手写编辑）

- **改文字内容**：直接打开对应的 `.html`，找到页面里的文字改即可（导航、页脚在每页顶部/底部，已用注释 `<!-- ===== 导航 ===== -->` 标出）。
- **改配色 / 字体 / 圆角 / 阴影**：只改 `css/style.css` 顶部的 `:root { ... }` 变量，全站即时生效。
  - 主强调色 `--coral: #EE8266`
  - 主行动按钮 `--cocoa: #5C3A2E`
  - 字体 `--font-display`（标题）、`--font-body`（正文）
- **加 / 改页面**：复制任一 `.html` 改名为新页面，改 `<title>`、导航里加一个 `<a>` 链接并给当前页加 `active` 类即可。
- **换图片**：把新图片放进对应 `assets/` 子目录，再改 html 里 `src="assets/..."` 的路径。
- **中 / 英 切换**：导航右上角「中 / EN」可切换。目前为中文主文案；若要补充英文，在对应元素加 `<span class="en">English text</span>`（已有 `.zh` 中文 span）即可被切换显示。

## 部署上线（任选其一，都是静态托管）

- **GitHub Pages**：把整个文件夹推到仓库，Settings → Pages → 选 `main` 分支根目录。
- **Netlify / Vercel**：拖拽文件夹即可，无需构建。
- **任意虚拟主机 / 对象存储**：上传所有文件，保证 `index.html` 在根目录。

## 简历 PDF

「下载简历」按钮指向 `assets/resume.pdf`。**请把你的简历命名为 `resume.pdf` 放到 `assets/` 目录**，按钮即可正常下载。
